# BIOPATCH website

A responsive, static BIOPATCH concept storefront built with HTML, CSS and vanilla JavaScript. It is designed to be hosted on GitHub Pages.

## What's included
- BIOPATCH landing page, brand story and product information
- Adult BIOPATCH: ₹500 (10 plasters)
- Children's BIOPATCH: ₹600 (10 plasters + 5 markers)
- Working shopping bag with quantity controls and subtotal
- Checkout form for customer and delivery details
- Demo payment screen (no payment processing or real order submission)

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js` and this `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. Your website URL will appear in the Pages section.

## Customising
- Edit product names and prices in `script.js` inside the `PRODUCTS` object.
- Edit page text in `index.html`.
- Change colours, spacing and fonts in `style.css`.

## Important
This is a student project/demo storefront. The payment screen is intentionally non-functional. The form does not send customer information to a server, and the demo button does not charge a payment method or create a real order.

The herbal ingredients and product benefits are presented as part of the BIOPATCH concept, not as verified medical claims. Product materials, biodegradability, safety and any health-related effects would need appropriate testing before real-world sale.
